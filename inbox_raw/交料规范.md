# 素材交料规范（inbox_raw）

> 这个文件夹是外部通用运营知识的**唯一入口**。往里放素材，其余的（清洗、抽卡、复审、脱敏、入库、合成、发布、同步 AI 顾问）由管线处理。

## 文件夹用途

| 文件夹 | 放什么 |
|---|---|
| `抖音/` | 短视频文案、口播稿、视频字幕（文字版） |
| `小红书/` | 笔记文案 |
| `公众号/` | 文章**链接清单**即可（txt，一行一个 URL），不必手动复制正文 |
| `直播与短视频转写/` | 直播回放/视频的文字版或字幕导出 |

## 交料格式

1. **文字素材**：`.txt` 或 `.md`，一个文件一篇素材；文件名建议 `标题_作者_日期`，如 `起号七天的三个动作_某博主_2026-09.md`；
2. **公众号文章**：`公众号/链接清单.txt`，一行一个 URL，可标注建议分类；
3. **视频/直播**：必须先转成文字（字幕导出 / 口播稿 / 转写工具），管线只处理文本。

## 放进去之后

告诉助理「inbox_raw 有新素材」即可。管线会：清洗去口水 → 切块 → DeepSeek 抽卡（内置 18+3 条剔除规则：非蛋糕行业不相关、课程广告、成功学、营销吹嘘等一律剔除；作者角色化、保留原文链接）→ AI 复审 → 入库新主题卡片库 → 攒够 300 张卡合成独立文档（不够先挂《平台通用技能》汇总篇）→ 校验 → 发布官网 → 同步 Dify 知识库。

## 与既有知识的边界

- 新分类在官网「11-平台通用技能」分区，与既有实战篇（《抖音内容与直播》《小红书运营》《推广》等）**分列不混编**；
- 既有篇 = 蛋糕行业真实场景（带一手数字）；新篇 = 平台通用方法论（标注来源链接）；
- 个人层（personal/、personal-vault/）与原始归档永不进入这条管线。
